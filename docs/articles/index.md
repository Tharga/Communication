# Articles

Guides for using Tharga.Communication.

- **[Getting started](getting-started.md)** — install, minimal server/client setup, configuration via `appsettings.json`.
- **[Messaging](messaging.md)** — `PostAsync` (fire-and-forget), `SendMessage` (request-response), and message handler discovery.
- **[Subscriptions](subscriptions.md)** — server-driven subscriptions with type-based and data-based granularity, including the `PostIfSubscribedAsync` convenience.
- **[Authentication](authentication.md)** — the pluggable `IApiKeyValidator`, default keys-array validator, custom validators (including Platform-backed lookups), and client identity overrides.
